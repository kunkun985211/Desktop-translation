# Desktop Translation · 划词助手

面向 Ubuntu 20.04、22.04、24.04 的 X11 桌面划词工具。选中文字后，在选区上方选择「翻译」或「解释」；结果也优先放在上方，空间不足时放到下方，留出间距。点击窗口外部可隐藏。

- **翻译**：自动识别所选文字的语言，翻译为中文。
- **解释**：用中文说明含义，结合 VLA、机器人学习及编程背景；默认 2～4 句话，通常 80～160 字，简单词更短。可在结果窗口继续追问，明确要求详细时再展开。
- **后台运行**：托盘菜单提供设置、暂停与退出；登录自启可在设置中开启。
- **API 可选**：支持 DeepSeek 和 OpenAI 兼容接口，自填服务地址、模型及可选 Tracking ID，保存后可随时修改。

## 安装与运行

在 Ubuntu 桌面的普通用户终端中执行：

```bash
git clone https://github.com/kunkun985211/Desktop-translation.git
cd Desktop-translation
./setup.sh
./run.sh
```

`setup.sh` 通过 apt 安装系统 Python、GTK3、Secret Service 和托盘依赖，使用 `/usr/bin/python3` 创建带系统包访问权限的 `.venv`，再安装固定版本的 python-xlib 和当前用户的应用入口。只有安装系统依赖需要 sudo；请不要以 root 身份运行整个桌面安装或应用。

安装后可在应用列表搜索「划词助手」，或运行 `~/.local/bin/selection-assistant`。请保留克隆目录及其路径。默认不开启登录自启，可在设置中开启。

请在登录界面的齿轮菜单选择 **Ubuntu on Xorg**。Wayland 会话不支持全桌面取词；仅把程序强制放到 XWayland 中运行也不能解决这一限制。

在本项目目录运行：

```bash
./run.sh
```

首次启动会打开 API 设置。选择服务、填写配置，点击「保存并开始划词」后会持久保存，后续从托盘「设置」可修改。

| 字段 | 填写说明 |
| --- | --- |
| API 类型 | `DeepSeek` 或 `OpenAI 兼容接口`。兼容模式要求服务支持 Chat Completions 的流式响应。 |
| 服务地址 | 平台给出的 Base URL，例如 `https://api.example.com/v1`，也接受完整 `/chat/completions` 地址。默认 HTTPS；HTTP 只允许本机 `localhost`、`127.0.0.1` 或 `[::1]`。 |
| 模型 | 平台提供的模型名称。DeepSeek 默认 `deepseek-flash`，关闭思考模式；兼容模式由用户填写。 |
| Tracking ID | 可选，平台分配的账号或密钥标识。仅在本机保存以区分凭据，不作为通用请求头、项目 ID 或 API 鉴权参数发送。平台没有此字段时留空即可。 |
| API Key | API 鉴权密钥，输入后存入系统密钥环。当前配置已有 Key 时留空可保留，输入新 Key 可替换。 |

兼容模式按照 [OpenAI Chat Completions 官方文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)使用 Bearer 鉴权及流式聊天请求，只发送 `model`、`messages`、`stream` 三个参数，不发送 DeepSeek 专有参数。需要额外项目头、云厂商专用签名、原生 Anthropic/Gemini 或 Responses API 的服务不在本版本范围内。

只有点击翻译、解释或发送追问才会调用所选 API。保存配置不会验证余额或调用付费模型。改变服务、模型、Tracking ID 或 Key 后会关闭并清空当前阅读会话，避免将旧对话发送给新服务。

已有密钥时，可用 `./run.sh --background` 启动后台监听而不显示设置窗口；尚未配置密钥时仍会打开设置。运行 `./run.sh --show-last` 或使用托盘中的「打开上次结果」可恢复当前进程的上次结果。对话保留在运行进程中，退出程序后不保留。

安装当前用户的应用入口：

```bash
python3 install.py
```

之后在 GNOME 应用列表搜索「划词助手」，或运行 `~/.local/bin/selection-assistant`。安装无需 sudo，默认不开启登录自启，也不会把源码复制到其它位置；请保留本项目目录及其路径。

运行环境在每台目标电脑上重新创建，不分发开发电脑的 `.venv`、`.runtime` 或二进制库。Ubuntu 20.04 使用系统 Python 3.8，22.04 使用 3.10，24.04 使用 3.12；三个版本统一使用系统 GTK3 和 Ayatana AppIndicator。不要用 Conda 或其它 Python 替换系统解释器来创建这个虚拟环境，否则可能无法加载系统 PyGObject。

已有依赖、只准备虚拟环境时，可运行 `./setup.sh --skip-system-packages --no-desktop`。这两个开关也用于 CI，不安装桌面入口、不启动应用。完整参数见 `./setup.sh --help`。

## 使用方式与范围

1. 在浏览器、PDF 阅读器或 IDE 中，用鼠标拖选文字或双击选词。
2. 在附近出现的浮条点击「翻译」或「解释」。
3. 阅读流式结果；解释窗口内可输入后续问题并继续对话。
4. 点击其它位置隐藏窗口并停止尚未完成的请求；在窗口内滚动、复制、输入时保持显示。

只有完整回答会进入后续追问的上下文，失败或停止的部分回答不会加入。再次选词并点击功能会开启新会话；需要接着上次内容追问时，请通过 `--show-last` 或托盘恢复结果。

仅支持 **X11** 会话和应用实际提供的可选文字，不包含 OCR。图片、扫描版 PDF、以画布绘制且无法选取的文字不会被识别。应用对 X11 选区的支持可能不同，尤其是嵌入式 PDF 和自定义编辑器，需要按下方步骤实机验收。

定位使用鼠标按下与释放范围估计选区，上下预留 24 个逻辑像素，再留 12 像素窗口间距；不是应用返回的精确文字矩形。超大字号、拖选时自动滚动等情况需要单独检查。上下均放不下时会缩小可滚动区域或使用空闲侧边；没有足够空间时提示减少选文，避免强行覆盖估计选区。结果窗口可拖动标题调整位置。

## 密钥与隐私

API Key 仅保存到系统 Secret Service 密钥环，不写入本项目、普通配置或日志。凭据按 API 类型、规范化服务地址和 Tracking ID 隔离；切换归属后不会借用其它服务的 Key。原有默认 DeepSeek 配置及其密钥继续可用。密钥环需要在当前桌面会话中可用并解锁；若保存失败，请先检查系统密钥环。卸载应用入口会保留密钥与配置。

API 类型、服务地址、模型、Tracking ID 及暂停状态保存在 `~/.config/selection-assistant/settings.json`，权限为 `0600`；Tracking ID 应是标识，不要在该字段填写密钥。

点击功能后，所选文字和必要的解释对话上下文会发送给设置中选定的服务地址。关闭窗口会停止未完成的请求，旧请求的后续响应不会重新打开窗口。

以下是建议实机检查的用例，不表示已经全部验证通过。

| 场景 | 操作与预期 |
| --- | --- |
| 浏览器、PDF、IDE | 分别拖选一段文字和双击单词，确认浮条出现且结果对应当前选区。 |
| 多语言翻译 | 依次选取英文、日文及混合语言段落，确认默认结果为中文。 |
| VLA 解释与追问 | 选取 `action chunking` 等术语，点击解释，再追问与 π₀.₅ 的关系，确认上下文连续。 |
| 点击与焦点 | 在结果内滚动、选取文字、输入；再点击外部空白区域，确认窗口按预期保留或隐藏。 |
| 快速更换选区 | 请求尚未结束时关闭窗口并选择其它文字，确认旧结果不会混入新结果或重新弹窗。 |
| 恢复上次结果 | 隐藏结果后运行 `./run.sh --show-last`，确认恢复当前会话；中断的回答不加入追问上下文，再次选词并点击功能开启新会话。 |
| 屏幕边缘 | 在四角、高分辨率与多屏边缘选词，确认浮条和结果可见、可操作。 |
| 空白与长选区 | 选择空白、超长文章或代码块，确认不会卡住或显示过期结果，并有合理提示。 |
| 无网络或中断 | 断网后点击功能、流式生成中断网，确认有可读错误且界面仍可关闭、继续使用。 |
| API 拒绝 | 使用无效 Key、余额不足、限流或不可用模型时，应显示对应错误；修正设置后可再次请求。 |
| 密钥环 | 锁定密钥环或取消解锁，确认保存失败不会降级为明文存储。 |
| 切换 API | 修改类型、服务地址或 Tracking ID，确认 Key 输入框清空、仅使用该归属的凭据，旧会话不会发送给新服务。 |
| 配置持久化 | 保存自定义 URL、模型、Tracking ID 与 Key，退出并重新启动，确认配置恢复；留空 Key 保留原值，输入新 Key 可替换。 |
| 托盘与自启 | 暂停后选择文字不出现浮条，恢复后正常；开启自启后重新登录检查，关闭自启后再次检查。 |

遇到网络错误，先检查网络，再从浮条重新发起请求；遇到余额不足、权限或模型错误，检查所选服务的账户、地址和模型配置。无文字浮条时，先确认托盘未暂停、当前登录会话为 X11，并检查源应用是否支持文字选取。终端执行 `./run.sh` 可查看启动错误。

## 卸载应用入口

先从托盘退出，再运行：

```bash
python3 install.py --uninstall
```

该命令仅移除本项目安装的桌面入口、命令链接、图标和带项目标记的登录自启入口；保留源码、普通配置以及 Secret Service 中的 API Key。

仅退出正在运行的单实例程序，也可以执行 `./run.sh --quit`。

## 开发验证

离线回归测试（不调用远程模型 API；窗口测试需要当前 X11 桌面，会短暂显示测试窗口）：

```bash
.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v
```

在隔离的虚拟显示器中执行（需要 `xvfb`、`xauth`、`dbus-x11` 和中文字体）：

```bash
XDG_SESSION_TYPE=x11 xvfb-run -a -s '-screen 0 3840x2160x24' \
  dbus-run-session -- .venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v
```

跨应用交互测试会打开独立的临时测试资料，并模拟鼠标操作；执行期间请暂时不要操作鼠标：

```bash
.venv/bin/python tests/smoke_apps.py --interactive
```
